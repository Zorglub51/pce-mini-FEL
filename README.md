This is a command line tool to put a PC Engine mini, Turbografx16 mini or Coregrafx mini in FEL mode.
You must add package LibUsbDotNet

Instructions :
- console if off and plugged to the PC via a data & & power micro-USB / USB-A cable.
- start the program ... it waits for the console to appear on a USB port
- turn the console on
- wait for the program to finish & exit
- done ! Congratulations, your console is in FEL mode and you can use sunxi-fel.exe
